📑 Tender Analysis & Tender Register

TenderMate stores GeM and Department ATC separately and determines the governing precedence from the tender documents. An explicit precedence clause in the tender is recorded; otherwise the TenderMate default is Department ATC priority.

📎 Source Documents & Automatic Analysis

Select the GeM PDF and Department ATC PDF. TenderMate reads text from the PDFs in your browser and fills the structured tender fields. The PDF files themselves are not uploaded to GitHub.

🔄 Tender Lifecycle

TenderMate follows the tender from GeM publication through ATC review, bid preparation, EMD, bid submission/evaluation, award or EMD return, Work Order, SD/APS, supply, bills and final release of SD/APS. Use the Workflow Stage and payment/status fields above to keep the tender state current.

📋 Work Orders

First select the Tender / GeM ID that was awarded, then upload the Work Order. Every saved Work Order is linked to that selected tender and automatically synced to Supabase. You can add multiple Work Orders to the same tender.

The selected tender determines the linked GeM ID and Division. If one tender has multiple Work Orders, upload each Work Order against the same tender.

💰 Work Order Rate & Quantity Register

This register is automatically built from saved Work Orders and linked Tenders. GeM ID is retained; Year and Work Order columns are intentionally omitted.

APS: 10% of (Estimated Amount − Contract Value) only when Contract Value is more than 10% below the Estimated Amount. SD: 3% of Contract Value. The linked tender ATC controls the applicable rule where it provides a different percentage or condition.
